# NexHealth v0.4 — pharmacy marketplace
Local development only, fictional data. Node 22.13+; use Node 24 LTS. Stop old backend and frontend. Back up the old project, especially data/network.sqlite and .env. Extract this release into a separate directory; copy your existing .env and data directory into it while the old server is stopped. Existing requests without kind are treated as donations. Never share .env. Run npm install, npm test, npm run server, then npm run dev in a second terminal. Open http://localhost:5173. Existing administrator credentials remain in the database.

Practice: Medication assistance creates donation requests; Purchase orders creates purchase requests. Pharmacy: Donation feed, Purchase feed, My fulfilment. Purchase quotes use ZAR unit prices; acceptance and fulfilment are recorded, but payment, tax, invoices and stock integration are not implemented. Existing prescription attestation and batch/expiry checks apply to both. Admin approves providers manually. Background worker persists administrative alert snapshots every minute; AI summary remains on demand. No external messages or autonomous AI actions. No production security or regulatory validation. Frontend build and live AI unverified. Keep local only.
